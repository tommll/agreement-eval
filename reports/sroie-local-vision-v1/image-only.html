How this was run

Model
Qwen3.5-4B, Q4_K_M GGUF, with its F16 vision projector, served by llama.cpp (build b10785)
Input
The receipt JPEG only, capped at 1,024 image tokens. The prompt says no OCR text is available.
Prompt and decoding
The detailed prompt, temperature 0, JSON-schema-constrained output, thinking disabled
Hardware
Intel i7-1365U laptop CPU, 8 threads. The vision encoder also runs on the CPU.
Scoring
Exact match after per-type normalization. The LLM judge was off.
Caveat
12 receipts is a small sample. Treat the per-field counts as indicative, not precise.
